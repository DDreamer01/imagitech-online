## Writeup conventions

- In PortSwigger writeups (especially the MCP Server Vulnerabilities folder), always **pretty-print JSON code blocks** with two-space indentation. Do not paste minified one-line JSON into writeups.
- Preserve the author's original wording in writeups; limit edits to grammar and spelling unless explicitly asked to rewrite.
- Mask API keys and credentials in writeups the same way as flags (first four and last four characters, e.g. `OVM…R8Zbe`), including in screenshots. Exception: when the writeup depends on the reader seeing a change to a key (for example, tampering with a token), show the key in full in both text and screenshots.
