A collection of `cmd` / PowerShell commands learned from the **HackTheBox Intro to Windows Command Line** module.

> Similar to Linux `man`, Windows has `help` for inline documentation — e.g. `help dir` or `command /?`

---

## 1. Viewing & Listing Directories

### `dir`

Lists the contents of a directory.

```cmd
dir
dir C:\Users
```

### `cd` / `chdir`

Changes the current working directory.

```cmd
cd Documents
chdir C:\Windows\System32
```

### `tree /f`

Recursively lists all files and folders within the specified path.

```cmd
tree /f
tree C:\Users\Admin /f
```

---

## 2. Create a New Directory

### `md` / `mkdir`

Creates a new directory.

```cmd
md NewFolder
mkdir C:\Projects\MyApp
```

---

## 3. Delete Directories

### `rd` / `rmdir`

Deletes a directory. Without flags, only works on **empty** directories.

```cmd
rd EmptyFolder
rmdir EmptyFolder
```

Use `/s` to delete a non-empty directory (including all contents):

```cmd
rd /s NonEmptyFolder
```

---

## 4. Move a Directory

### `move <source> <destination>`

Moves a directory (including its children) to the destination. The source is deleted after the move.

```cmd
move OldFolder C:\NewLocation\OldFolder
```

---

## 5. Copy a Directory

### `copy <source> <destination>` / `robocopy`

Copies a directory to the destination. The source remains intact.

```cmd
copy file.txt C:\Backup\file.txt
```

For copying entire directory trees with more control, use `robocopy`:

```cmd
robocopy C:\Source C:\Destination /E
```

> `/E` copies all subdirectories including empty ones.

---

## 6. List Files & View Their Contents

### `more`

Displays file contents one page at a time (useful for large files).

```cmd
more file.txt
```

### `type`

Prints the entire contents of a file to the terminal. Can also be used for redirection:

```cmd
type file.txt
type passwords.txt >> secrets.txt
```

---

## 7. Create and Modify Files

### `Echo (Write to File)`

Writes text to a file using output redirection. Use `>` to create/overwrite and `>>` to append.

```cmd
echo Check out this text > demo.txt
echo More text >> demo.txt
```

### `fsutil`

Low-level file utility. Can create a new file of a specified byte size:

```cmd
fsutil file createNew for-sure.txt 222
```

### `ren` / `rename`

Renames a file.

```cmd
ren demo.txt superdemo.txt
rename oldname.txt newname.txt
```

---

## 8. Deleting Files

### `del`

Deletes one or more files.

```cmd
del file-1.txt
del *.log
```

### `erase`

Alias for `del` — can delete multiple files at once.

```cmd
erase file-3.txt file-5.txt
```

## 10. Finding Files and Directories

### Where

```cmd
C:\Users\Adminuser>where calc.exe
C:\Windows\System32\calc.exe
```

Find files recursively

```cmd
PS C:\Users> where.exe /R C:\Users\ waldo.txt
C:\Users\MTanaka\Favorites\waldo.txt
```

Using wildcards

```cmd
C:\Users\student\Desktop>where /R C:\Users\student\ *.csv
C:\Users\student\AppData\Local\live-hosts.csv
```

### Find

Used to search for text strings in a file

```cmd
C:\Users\Adminuser\Downloads\fixed>find "colorama" requirements.txt

---------- REQUIREMENTS.TXT
colorama>=0.4.6
```

## 11. Environment Variables

### Set

Set is used to create a variable

```cmd
C:\Users\Adminuser>set NAME=Joseph
```

### Setx

> The setx command saves environment variables permanently to the registry for future sessions, but it does not update the environment of the currently open Command Prompt window.
> To use the variable, you have to open a new window (For permanent variables)

```cmd
C:\Users\Adminuser>setx COLOR Brown

SUCCESS: Specified value was saved.
```

### Echo (Display Variables)

Echo is used to view variables global or local.

```cmd
C:\Users\Adminuser>echo %name%
JOSEPH
```

```cmd
C:\Users\Adminuser>echo %COLOR%
Brown
```
