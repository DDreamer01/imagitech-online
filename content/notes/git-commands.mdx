Git is a version control system, I mostly use when writing contents for my website and pushing/commiting to Github > my server.

### Pull Pull

Fetch updated contents from Github (at the same time bypass a particular error I face with my feed.xml.)

```bash
git reset --hard main
git pull origin main
```
