Quick reference note and command log for Passwordless SSH Login.

### 1. Generate Ed25519 key

```bash
ssh-keygen -t ed25519 -C "email@example.com"
```

### 2. Generate RSA key

```bash
ssh-keygen -t rsa -b 4096 -C "email@example.com"
```

### 3. Copy key to server

```bash
ssh-copy-id user@server
```

### 4. Log in with key

```bash
ssh user@server
```
